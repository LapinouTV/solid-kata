# SOLID Kata

Hands-on kata covering the five SOLID principles, with a Python example
for each (`01_srp` → `05_dip`).

## Slides

A [Slidev](https://sli.dev) presentation lives in [slides/](slides/slides.md).

```bash
cd slides
npm install
npm run dev      # start the presentation locally
npm run build    # build a static, deployable version
```
